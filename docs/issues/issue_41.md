# Issue 41: OSCAR OCR Integration API

## Description

Task from the project plan: Integrate OCR with OSCAR backend.

This issue tracks the integration of the Optical Character Recognition (OCR) system with OSCAR.
The system must:
1. Authenticate with OSCAR.
2. Retrieve alarming occupancies by polling.
3. Download video files for processing.
4. Process video with OCR.
5. Submit the extracted container number back to OSCAR via the Adjudication command endpoint.
